# Formato 3 · Opinione controcorrente
Quando qualcosa che "tutti dicono" nel tuo settore ti sembra falso.

## Struttura
1. **Gancio**: la frase che tutti dicono, poi la smentita
2. **Concessione**: "Ok, la sto esagerando…" (ti rende credibile)
3. **Prova**: un esempio dalla vita normale
4. **Collegamento col lavoro**: cosa vuol dire per il tuo cliente ideale
5. **Un dato o una fonte**, se c'è (link nel primo commento)
6. **Da portare a casa**: 2–3 punti pratici, oppure una battuta

Errori: prendersela con persone riconoscibili; restare nel lamento senza la parte pratica.
