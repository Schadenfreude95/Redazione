# Formato 5 · Caso cliente raccontato come conversazione
Dopo una call o un progetto in cui hai scoperto un problema che il cliente non vedeva. Di solito rende molto più del caso studio "a risultati".

## Struttura
1. **Gancio**: il ribaltamento ("Il problema non è X. Il problema è tutto il resto.")
2. **La scena**: 4–8 battute di dialogo vero, corte
3. **La scoperta scomoda**
4. **La tua posizione**: perché è giusto dirlo al cliente, anche se rischi il no
5. **Il risultato in UNA riga**, se c'è
6. **Chiusura**: domanda o frase secca

Errori: partire dai risultati; liste di azioni tecniche; rendere il cliente riconoscibile senza permesso.
